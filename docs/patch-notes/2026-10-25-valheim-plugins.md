# Valheim modpacks and Wisp plugins

- Wisp → Plugins adds reviewed installation, enable/disable controls, and a sandboxed Wasm plugin host.
- The first plugin, Valheim Modpacks, pins Thunderstore dependencies and shares encrypted pack revisions with friends, groups, and server channels.
- Members can review a shared pack and create a separate local BepInEx profile with verified downloads. Installing a pack never starts the game or changes another member’s setup.
- This first release uses locally installed plugin packages. Browsing, automatic updates, and game launching are still to come; in-game mod compatibility has not been verified.
