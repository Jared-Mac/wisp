# Server plugins, without folder hunting

- Server admins can add Valheim Modpacks from the built-in Wisp catalog.
- Enabled plugins appear directly on the main desktop view for all server members.
- Click a plugin to prepare it automatically and manage mod lists, shared revisions and local profiles.
- Plugin packages are verified against the reviewed catalog. Sharing packs and installing game mods remain explicit actions.
- Removing a server plugin preserves existing drafts and game profiles.

This updates the Linux desktop and server. Windows and Android catalog UI support is not included in this release.
