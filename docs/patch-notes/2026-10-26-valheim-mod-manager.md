# A dedicated Valheim mod manager

- Valheim Modpacks now opens its own manager inside Wisp, separate from plugin administration.
- Search and filter mods, inspect versions and sources, add private ZIPs, update pinned versions and deliberately remove mods from a pack.
- Shared packs and local installation details have their own tabs; exact dependency-list editing is available under Advanced.
- The layout adapts to narrow windows, and changing conversations protects unsaved edits.

Linux desktop UI update. Existing server APIs and modpack formats are unchanged.
