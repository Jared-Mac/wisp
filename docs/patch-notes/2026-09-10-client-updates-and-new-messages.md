# Smoother updates and clearer chat lists

- Fixed an update-installation error that could reject a valid client download. Existing accounts and settings stay intact.
- Added a “New messages” divider and a “New” button to jump to messages you missed. Returning to a chat keeps them unread until you interact with it and reach the latest messages.
- Removed duplicate friends from the inline server-member list. “Other members” shows nonfriends and pending requests by default, while its search button opens the complete server directory.
