# Android test update

**Android 0.5.0-test** adds clearer voice feedback, faster joins, photo/file messages, reactions, camera and video-only screen sharing.

**Pixel and Samsung use the same APK.**

1. **Desktop first:** Settings → Updates → Check for updates → Update now (if offered). After relaunch, if “Finish updating your account” appears, enter your **current password** and press **Continue**. Already upgraded? Skip confirmation.
2. **Phone:** Open **[wisp.you/android-test](https://wisp.you/android-test)**. Download the APK. If prompted, tap **Settings → Allow from this source**, then return and tap **Install**. No USB or developer mode needed.
3. Open Wisp, allow notifications, and sign in with your **private sign-in username and current password**, not your display/public username. Your existing keys restore automatically; no recovery-file transfer.

**Updates:** Return to the same link and install newer APKs over Wisp. **Do not uninstall**; keep your account and settings.
