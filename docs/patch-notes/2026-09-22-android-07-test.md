# Android 0.7.0 test update

- Cleaner chat with Grouped, Compact and Soft groups layouts (Soft groups is the Android default), a smaller header/composer, and a black system navigation area.
- Message previews in notifications, with a Hide message previews setting; live typing; server-admin kick/ban/unban controls.
- In-app update downloads with integrity checks and Android's install confirmation.

**Pixel and Samsung testers:** open https://wisp.you/android-test once, download/open the APK, allow installs from your browser if prompted, then tap **Install** over Wisp. **Do not uninstall**—existing sign-ins stay intact. No developer mode or USB needed. Samsung Auto Blocker help is on the page.

Fresh installs: sign in with your private sign-in username and current password, and allow notifications.

After this update: **Settings → Check for updates → Update Wisp**, then Android's **Install** confirmation (allow installs from Wisp if prompted). The same link remains a fallback.
