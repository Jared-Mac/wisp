### A new look, with room to make it yours
- Soft Graphite is the new desktop default, joined by Daylight and Hearth. Terminal and classic styles remain available, with Wisp's original branding throughout.
- Settings now put common choices first, with searchable, expandable advanced controls and easier appearance previews.
- Compact voice and call buttons keep controls close to the rooms. Tooltips explain each icon.
- Drag the activity sidebar down to a slim rail. Controls adapt, the width is remembered, and full collapse stays a separate action.
- New sounds confirm microphone mute/unmute and deafen/undeafen, with sound preferences and custom recordings.
- Hide user avatars in Appearance, or upload and remove your own picture in Profile. Profile-picture sharing requires the matching server update.
