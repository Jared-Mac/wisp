# One modpack for the whole server

- Server plugins now open a shared server-wide pack by default, with no channel selection required.
- Admins publish revisions once; members can open and install that pack on their own PCs.
- Personal drafts and channel-specific sharing remain available. Copy an existing personal draft with **Use personal draft**.
- Unpublished edits stay private, and private mod ZIPs remain encrypted. New members may need an admin to republish the pack for their membership.
