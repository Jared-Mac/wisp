# Encrypted backup on Android

- **Android 0.4.0-test** is available from [the Android test page](https://wisp.you/android-test). Secure sign-in restores your existing encryption identity and saved trust settings without transferring a recovery file.
- Enable backup once on an existing trusted desktop in **Settings → Profile → Account backup**, then sign in on Android. Interrupted setup can be resumed; signing in never joins voice or starts media automatically.
- Android supports native secure-password recovery and trusted-device backup repair after an email reset.
- Fixed desktop account imports being blocked by temporary files left by an interrupted write. Existing keys and committed room records are preserved.
