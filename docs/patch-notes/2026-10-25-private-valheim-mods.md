# Share private Valheim mods

- Valheim Modpacks 0.2.0 adds **Add private mod ZIP**. Review a local mod package and include it in a pack without uploading it to Thunderstore.
- Shared revisions carry private mod files inside an encrypted attachment. Friends import the pack and choose when to install their own verified profile.
- Private and public mods can be combined. Changed ZIPs require another review, and existing game installations and older profiles remain untouched.
- Both members need the updated Wisp client and Valheim plugin. ZIPs need a package manifest; private files are limited to 128 MiB per pack. A mod’s multiplayer compatibility still depends on the mod itself.
