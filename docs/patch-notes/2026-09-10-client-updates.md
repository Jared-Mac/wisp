# Easier client updates

- Wisp checks for updates at launch and while running. Automatic installation waits until voice, streams, drafts, and transfers are finished.
- New Updates settings let you disable automatic installation or checks, choose the check interval, check manually, and install an available update.
- Fixed the account header staying on “Joining” after voice connects.
- Dashboard storage cleanup now refreshes connected clients automatically.

Existing clients need this build installed once to receive future in-app updates.
