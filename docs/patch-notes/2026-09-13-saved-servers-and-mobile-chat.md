# Saved servers and smoother mobile chat

- Wisp can securely sync your saved server list between desktop and Android 0.6.0-test with the matching server update. Each server keeps its own sign-in; restoring the list never joins voice or starts media. Use **Sync now** or the existing automatic-sync setting to control it.
- **Android 0.6.0-test:** Chat follows new messages while you’re at the bottom. Scrolling back keeps your place, with a notification badge and button to return to new messages.
- **Android:** More compact room and people cards leave extra space for chat. The saved-server picker keeps each server’s messages, drafts and account separate.
- **Android:** Phone audio defaults to the speaker, while Bluetooth and wired headsets take priority. **Settings → Voice** can change the phone default to **Earpiece**.

Android testers can install **0.6.0-test** over their existing app from the [same download page](https://wisp.you/android-test). Keep the app installed to preserve its local account data.
