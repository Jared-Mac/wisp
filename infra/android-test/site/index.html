Install

  1. Open this page on your Android phone and download the APK.
  2. Open the downloaded file. If Android asks, tap Settings, enable Allow from this source, then return and tap Install.
  3. Open Wisp, allow notifications, and sign in with your private sign-in username and current password.

USB debugging, a computer, and Android Studio are not needed. You can turn off your browser's install permission afterward.

Samsung says Auto Blocker prevented installation?

Temporarily turn off Settings → Security and privacy → Auto Blocker, install the APK, then turn Auto Blocker back on. Repeat for updates if needed. Samsung help

Update

Return to this page and install the newer APK over Wisp. Keep the existing app installed to preserve your sign-in and settings.

If Android reports a conflicting signature, keep the installed app and ask for help instead of uninstalling it.
